# Data

Os dados científicos não são misturados ao código-fonte.

## RAW principal

Fonte:

**Brazilian E-Commerce Public Dataset by Olist**

Identificador Kaggle:

`olistbr/brazilian-ecommerce`

O projeto utiliza os nove arquivos relacionais originais da distribuição Olist.

Os hashes e tamanhos da cópia utilizada nos experimentos estão registrados em:

`docs/EXTERNAL_AND_LARGE_FILE_MANIFEST.csv`

## Regra de governança

A camada RAW é imutável.

Os dados não são modificados por auditorias, feature engineering ou treinamento.

## Dados externos

As fontes externas utilizadas nas análises espaço-temporais são documentadas
no Registry, nos manifests e na documentação metodológica do projeto.

Dados volumosos podem ser readquiridos/transferidos separadamente em vez de
serem armazenados diretamente no histórico Git.
